二、损失函数

最常用的损失函数是均方误差（MSE）：

$$
L(w, b) = \frac{1}{m} \sum_{i=1}^{m} \left( \hat{y}i - y_i \right)^2
= \frac{1}{m} \sum{i=1}^{m} \left( w^\top x_i + b - y_i \right)^2
$$

五、常见坑

  1. 特征量纲差异大 → 一定要先 StandardScaler。
  2. 学习率过大 → 损失震荡甚至发散。
  3. 特征共线性 → 接近奇异，考虑岭回归。
  4. 欠拟合 vs 过拟合 → 多项式回归 + 正则化是良药。
